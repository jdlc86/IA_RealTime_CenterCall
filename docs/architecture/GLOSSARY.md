# Glosario

- **Fast Worker:** control plane Cloudflare de Gemini.
- **Fast Media Edge:** media plane Cloud Run que une Telnyx y Gemini Live.
- **Hot path:** forwarding continuo de audio; no admite trabajo evitable.
- **Admission:** validaciones anteriores a emitir credenciales e iniciar media.
- **Bootstrap:** configuración inmutable y tenant-bound de una llamada.
- **Capability:** concesión explícita que habilita una clase de efecto.
- **Authority:** fuente aceptable de autorización para una tool.
- **Effect:** clase de impacto de una tool.
- **Evidence:** evidencia del turno/contexto exigida por la policy.
- **Receipt:** comprobante opaco, ligado a llamada/function call, necesario para ejecutar.
- **Sideband:** control o telemetría fuera del forwarding continuo.
- **Vertical:** reglas y datos propios del negocio de un tenant.
- **Kernel transversal:** seguridad, voz, tools, handoff, tiempo y comunicación comunes.
